# Historias de Usuario - SisFin

**HU01 - Registro de usuario**  
Como administrador, quiero registrar un nuevo usuario para gestionar su información en el sistema.

**HU02 - Eliminación de usuario**  
Como administrador, quiero eliminar usuarios para mantener la base de datos actualizada.

**HU03 - Visualización de usuarios**  
Como administrador, quiero ver la lista de usuarios para validar que están correctamente registrados.
